# Security Policy

## Reporting a Vulnerability

Please report suspected security vulnerabilities through GitHub’s **Report a vulnerability** option on the repository’s Security tab. This provides a private channel for sharing details with the maintainers.

**Do not report vulnerabilities in public Issues, Discussions, or pull requests.** Avoid sharing vulnerability details publicly until maintainers have had an opportunity to investigate and coordinate a response.

Include, where possible:

- The affected xtrc version, release, or commit
- The operating system and relevant environment details
- Steps to reproduce and the potential impact
- Any known workaround or mitigation

Please avoid including real credentials, private data, or other sensitive information in a report.

## Supported Versions

Security fixes are intended for the latest release and the current `main` branch.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| `main` | Yes |
| Older releases | No |

## Response and Disclosure

There is no guaranteed response time. Please allow maintainers time to investigate and coordinate any disclosure before publishing vulnerability details.

## Bounties

The project does not offer bounties or paid rewards for vulnerability reports.
